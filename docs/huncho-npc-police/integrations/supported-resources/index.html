Supported resources

Everything is detected on its own. Verified = written against that resource's code or docs. Untested = built from public docs but not yet run on a live server; the console says so when one is picked. Please report anything that doesn't work.

** These garages have no public impound function, so the car is taken off the street and nothing is written to the garage. Connect their impound in Other scripts if you want it there.

Forcing a script

To use a specific adapter instead of auto-detection, set it in Config.Bridge:

Config.Bridge.prison = 'builtin'

Script not listed? Most scripts can be connected from the config without Lua: Other scripts (no code). /npcpolicedetect lists running scripts that look unsupported.
